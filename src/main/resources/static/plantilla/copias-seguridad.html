Copias de seguridad

Guardá una copia de la base de datos o restaurá una copia anterior.

Demostración: esta página todavía no crea, verifica ni restaura archivos. Los controles están desactivados.

Una copia incluirá los datos que estén guardados en la base de datos. Los eventos, productos, tickets y movimientos de ejemplo de estas pantallas no están guardados allí y no se incluirán.

Crear copia de seguridad

La copia permitirá conservar la información de la base de datos en un archivo para guardarlo en otro dispositivo.

Ejemplo de nombre: caja-respaldo-2026-03-14.db

Disponible próximamente desde esta página.

Restaurar copia de seguridad

Permitirá seleccionar una copia anterior para recuperar los datos guardados en ella.

La selección y restauración estarán disponibles próximamente.

Antes de restaurar

Restaurar puede reemplazar datos actuales por los de la copia anterior. Para la futura función se prevé verificar el archivo, conservar una copia de la base actual y pedir confirmación antes de cualquier reemplazo.

Guardá las copias en un lugar protegido y, si es posible, en otro dispositivo.
